# Reusable business data contracts

Phase 5 uses the existing authenticated, tenant-scoped JSON API. These contracts are intended for apps/web and a future isolated read-only spatial consumer; they do not create a separate data store.

| Contract                     | Source / fields                                                                                   | Provenance and bound                                                                                                                                                                  |
| ---------------------------- | ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| CRM snapshot                 | /api/reports/summary; asOf, counts, current statuses, currency groups and truncation flags        | Verified current SQL facts; established creation/occurrence/completion definitions; no historical revenue/conversion inference                                                        |
| Business profile document    | /api/business/profile; version, updatedAt, data                                                   | Organization-visible owner/admin-provided declarations; optional bounded fields, storage consent and separate organization advisor-sharing approval                                   |
| Private preferences document | /api/business/preferences; version, updatedAt, data                                               | Current user only in current tenant. Journey, descriptive role, optional answers, planning/progress and private advisor consent. Never organization-wide user-directory data          |
| Goal page                    | /api/business/goals?page&search; content, page, totalElements, totalPages                         | Current persisted plans, 25 per page; complete filtered count, fixed deterministic ordering                                                                                           |
| Goal detail                  | /api/business/goals/{id}; id, version, title, description, dueDate, status, updatedAt, milestones | User-declared planning states, at most 20 milestones; optimistic version                                                                                                              |
| Milestone                    | id, title, dueDate, completed, taskId, taskStatus                                                 | completed is a manual declaration. taskStatus is the actual permitted active CRM task state or unavailable when archived; no silent synchronization                                   |
| Task preview                 | POST goal/milestone/task-preview; version + existing TaskRequest                                  | Five-minute current-session token, canonical task input; no operational creation until confirmation. Preview excludes model authority                                                 |
| Confirmation                 | POST /api/business/task-confirmation; token                                                       | Existing TaskService result, refreshed goal version; single-use and permission revalidation                                                                                           |
| AI business source           | intelligence message with scope=advisor, shareBusinessContext=true                                | Requires organization, private and per-question consent. USER_PROVIDED_NOT_INDEPENDENTLY_VERIFIED marker; current own profile/preferences and five goal samples, separate CRM summary |
| AI interpretation            | Existing sourced recommendation schema                                                            | Hypothesis/recommendation, not a factual profile field or a completed action                                                                                                          |

An unsaved/cleared profile is version=0, updatedAt=null, data=null; clients must not invent a replacement business identity. Saved writes supply the last observed version. Profile/goal conflicts are 409 and require refresh/review. UUIDs and relationship ownership are checked server-side, including composite database foreign keys.

Goals have calendar target dates; task dueAt is an Instant. The frontend converts a reviewed local task date-time to UTC and shows the canonical server preview. No camera, speech, room or gesture payload belongs in these contracts without a separately reviewed extension.

The model is not allowed to choose arbitrary routes or tools. Logical CRM source IDs map to existing /record-context?resource=...&id=... navigation; all data retrieval still requires active persisted membership. Empty, partial, expired, permission-denied and unavailable responses must remain distinct in every consumer.
